# Plan_Stock

Widget personnalisé Grist qui affiche le plan du stock (étagères A à Z, niveaux 1·2·3, zones au sol)
et met en évidence l'emplacement de l'article sélectionné.

- **Utilisation dans Grist** : ajouter un widget « Personnalisé », URL `https://lucienlf.github.io/Plan_Stock/plan-stock.html`,
  accès « Lire la table », puis associer la colonne **Emplacement** (et **Nom** si besoin).
- **Aperçu** : ouvrir `plan-stock.html` directement dans un navigateur → mode démo avec des données fictives.
- **Fonctionnement détaillé** : voir le commentaire en tête du `<script>` dans `plan-stock.html`.

Raccourcis : `/` rechercher · `Échap` fermer le panneau · molette = zoom · glisser = déplacer · double-clic = vue d'ensemble.
